# Hotel Database — SQL Coursework

A relational database design exercise for hotel operations.

The repository contains SQL scripts for entities such as hotels, rooms, reservations, clients, employees, payments, invoices, inventory, and services. It also includes entity-relationship diagrams.

## Contents

- SQL table and routine scripts in the repository root
- `diagramaHotelFinal.png` — database diagram
- `diagrama FINAL E-R.png` — entity-relationship diagram

## Using the scripts

Review the schema and routine scripts before running them in a local SQL database. Check object-creation order, database compatibility, and existing-table conflicts. This repository is coursework, not a deployed hotel management application.
